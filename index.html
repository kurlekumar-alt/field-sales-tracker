Google Sheets Shared Cloud Connection

Let your reps submit from anywhere and sync live to your Google Sheet.

Simple 3-Minute Setup:

  1. Open a new Google Sheet in your browser (e.g. named Field Sales Tracker).
  2. Click Extensions > Apps Script and paste the short script below.
  3. Click Deploy > New deployment > Web app (set access to Anyone), then paste the URL below!
Google Apps Script Code to Copy: 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.date,
    data.repName,
    data.areasCovered,
    data.docs,
    data.pharms,
    data.leads,
    data.orders,
    data.orderValue,
    data.comments
  ]);
  return ContentService.createTextOutput(JSON.stringify({status: "ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}
Note: Offline demo mode always works via localStorage.
